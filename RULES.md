# RULES — hard constraints for the loop (and for me)

Consolidates the no-fabrication / data-driven rules scattered across README, handoffs, and global CLAUDE.md. The loop enforces these mechanically where possible.

## Data
1. **No fabricated numbers. Ever.** A published figure is verified-with-`src` or flagged as an estimate. Nothing in between. (schema: `programVerified` with numeric data requires `src`.)
2. **JSON is the source of truth.** Edit `data/schools/*.json` or `data/shared/app-config.json`. **Never hand-edit `index1.html`** — it is generated by `scripts/build.js`.
3. **Stage 1 is local-data-only.** No `WebSearch` / `WebFetch`. Verification data lives in `data/verify-batch1-6.json` and `data/PENDING-RESEARCH-2026-09-05.md`. Value not in local files → append to `GAPS.md`, leave field EST-flagged, do NOT fetch.

## Change discipline
4. **One backlog item = one iteration = one commit** (or one revert). No scope creep across items.
5. **Every change passes two gates before commit:** `node scripts/validate.js` (objective) AND an **independent** adversarial-reviewer `claude -p` call (fresh context, judges the source diff cold).
6. **Revert on any gate failure.** `git reset --hard` to the pre-iteration commit + log why. Clean tree required to start.

## Deploy
7. **Never push/deploy without explicit user approval at a checkpoint.** A push to `main` auto-deploys via Vercel. Default is local-commit-only (`--push` opt-in, per-run).

## Privacy
8. Public copy must never contain the applicant's or parent's real name. (Deploy-copy sanitize step, per SONNET-HANDOFF.)

## Process
9. **Checkpoint after every batch:** self-audit against `GOAL.md` + this file + `DELIVERABLES.md`, produce a visible result (open the app + changelog + metrics), then stop for user go/no-go. Autonomy ramps up only as checkpoints keep delivering.
10. **Model selection is autonomous, never asked of the user.** The loop routes models by revealed complexity (Haiku triage → Sonnet for merges / Opus for judgment; reject escalates to Opus; reviewer stays Opus). Full policy in `OPERATING-MODEL.md`. Keep token usage optimal by default; improve the routing each run.
