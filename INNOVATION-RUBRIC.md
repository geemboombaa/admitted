# INNOVATION — rubric + definition of done

No oracle exists for "is this innovative," so this is a **structured-judgment** rubric: scored by an
**independent critic** (never the maker) and the **human** (taste anchor). It measures *quality of thinking*,
not correctness. A bug fix or a "done" feature that scores 0 on 1–5 is execution, not innovation.

## RUBRIC — score each 0 (fail) / 1 (weak) / 2 (strong)

### Core — must be ≥1, and no 0s (else it isn't innovation)
| # | Criterion | The question it must answer | Pass bar |
|---|-----------|------------------------------|----------|
| 1 | **Real problem** | Is it a genuine problem — whose, why it hurts, how we know? (5 Whys / "Are Your Lights On?") | Stated with evidence, not assumed |
| 2 | **Insight** | What non-obvious truth does this see that others miss? | Names something not-obvious that changes the approach |
| 3 | **Differentiation** | vs which *real* existing solutions, and what's specifically weak about theirs? | Named incumbents + their weakness + why we're different/better + why they can't trivially copy |
| 4 | **Value** | Painkiller or vitamin? Would the user switch for it? | Concrete pain/gain; user would actually change behavior |
| 5 | **Novelty** | New idea/approach/angle, or a rehash? | Not obvious from the current solution set |

### Quality angles — the relevant ones must be ≥1 (clever-but-shitty fails here)
| # | Criterion | Pass bar |
|---|-----------|----------|
| 6 | **UX / ease of use** | Genuinely simple, low cognitive load — not clever-but-painful |
| 7 | **Coolness / experience** | Creates a "whoa"; a user would show it to someone |
| 8 | **Feasibility / reality** | Buildable; grounded in real data/users/live competitors — not fantasy |

### Rigor of thinking — both required
| # | Criterion | Pass bar |
|---|-----------|----------|
| 9 | **Steelman survived** | The strongest counter-case was argued; the idea survived or adapted |
| 10 | **Pre-mortem** | "Assume it shipped and failed — why?" done; top risks named + addressed |

**Verdict:** PASS only if core (1–5) has no 0s, relevant angles (6–8) are ≥1, and 9–10 done — as judged by an
independent critic AND the human. Anything less = not innovation; send back or downgrade to "execution."

## DEFINITION OF DONE — an innovation item is done only when ALL hold
1. **Problem defined + validated** — evidence, whose, why — not assumed.
2. **Incumbents mapped** — who else solves this + what's specifically weak about theirs.
3. **Insight stated** in one sentence.
4. **Differentiation explicit** — why this beats them + why it's not trivially copyable.
5. **≥3 distinct angles pressure-tested** (from UX / ease / coolness / feasibility / security / addictiveness), each with a verdict.
6. **Steelman + pre-mortem done**, top risks addressed.
7. **Reality-check** — grounded in real data, a prototype, or real user/competitor contact (not vibes).
8. **Scored on the rubric by an INDEPENDENT critic** (not the maker) — no 0 on criteria 1–5.
9. **Human approved** at the checkpoint (taste anchor — irreducible).
10. **Concrete output** — a shippable artifact or a validated decision, not a document of intentions.
